The research question

Can local statistical behavior in a changing solar X-ray signal identify flare-like events, and can the observed rise phase distinguish B-class events from C-or-above events without using post-peak information or peak flux as a predictor?

Scientific pipeline

GOES X-rays→Cleaning→Rolling statistics→Anomaly detection→Events→NOAA→5 features→B / C+

Robust statistics

Mean/SD are complemented by median and scaled MAD so extreme flare values do not define the background scale.

Temporal integrity

Primary rise features use information available at or before the observed peak. Post-peak decay information is excluded.

Independent events

The ML unit is one deduplicated physical NOAA-aligned event, not one one-minute telemetry row.

Event morphology

Primary predictors: rise_slope, max_roc, mean_pos_roc, rise_duration_min, bg_flux. Peak flux is descriptive only.

Scientific limitations remain visible

  • N = 31 independent ML events; final test N = 7.
  • Ordinary Logistic Regression exhibits complete separation and convergence warnings.
  • Rise-rate predictors have high multicollinearity.
  • Detector selection and NOAA alignment influence the supervised event population.
  • No external validation across another interval, instrument or solar-cycle population.
  • This is severity nowcasting at the observed peak — not pre-flare forecasting.

Project context

This is an undergraduate statistical proof-of-concept and part of a broader exploration of astronomy, astrochemistry and data-driven space science. The specific project is most accurately described as heliophysics / statistical space-data analysis.
