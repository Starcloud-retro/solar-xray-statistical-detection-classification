07 · EVENT DATASET

How does a seven-day time series become only 31 machine-learning events?

The answer is not “we threw away almost all the data.” The project changes what one row means. First, one row means one minute. Later, one row means one independent physical event.

01 · START WITH THE TIME SERIES

At first, one row means one minute.

Across roughly seven days, the cleaned XRS-B file contains 10,078 time-stamped observations. Machine learning is not applied directly to these minute rows.

So what turns many neighboring minutes into one event?

02 · DETECTION CHANGES THE UNIT

Persistent unusual minutes are grouped into 115 event detections.

The detector does not label every high minute independently. It combines consecutive unusual behavior into event intervals with a START, PEAK and END.

But are all 115 detections official NOAA flares?

03 · NOAA IS AN INDEPENDENT REFERENCE

Detected events are compared with NOAA records rather than automatically treated as truth.

In the frozen alignment results, 32 detections matched NOAA, 80 detections had no NOAA match, and 3 NOAA events were not recovered.

An unmatched statistical detection is not automatically a false physical flare; it may be sub-B activity, noise, or activity not represented in the official list.

So why does the ML dataset construction mention 35 labeled rows and then 32 physical events?

04 · ONE PHYSICAL EVENT MUST EQUAL ONE ML EXAMPLE

The supervised event table contained 35 labeled rows, but three NOAA flares appeared twice.

For those three physical NOAA events, two detector segments referred to the same flare. Keeping both would give the same physical event extra influence in machine learning.

Deduplication keeps one primary detection for each physical flare, reducing 35 labeled rows → 32 independent physical events.

05 · CLASS ELIGIBILITY

Those 32 independent events contain B, C, M and one unspecified event.

After deduplication, the class counts are: 13 B, 17 C, 1 M and 1 U.

The frozen target is B vs C+, where C+ combines C and M. The one U event has no usable B/C/M target, so it is excluded.

06 · FINAL ML DATASET

The final supervised dataset has 31 independent labeled events.

The final class balance is 13 B and 18 C+. Each of these 31 rows is a physical event described by the same five rise-phase predictors.

The next question is no longer “where did 31 come from?” — it is “what information does each of those 31 event rows contain?”

THE DISTINCTION TO REMEMBER

There are three different datasets hiding inside one project.

10,078 time-series rows

Used to estimate background, detect unusual behavior and construct events.

115 statistical detections

Candidate event intervals created by the detector.

31 ML-eligible physical events

Independent labeled B/C+ events used in the final classification experiment.
