ROBUSTNESS CHECK

Does the result survive closer inspection?

AUDIT
CHECK 1 · LOOCV

Repeat the prediction with one event left out

Each event is held out once, the model trains on the other 30, and the held-out event is predicted. This checks whether the development/final result depends too heavily on one split.

CHECK 2 · CORRELATION

Three rise features tell very similar stories

rise_slope, max_roc and mean_pos_roc are strongly correlated because they all describe the rising phase.

CHECK 3 · VIF

Redundancy makes individual coefficients unstable

VIF is very high for the three rise-related predictors. Logistic Regression coefficient magnitudes should therefore not be interpreted as stable physical effects.

CHECK 4 · LIMITATIONS

The result is a proof of concept

Only 31 ML-eligible events exist, the final test has N=7, ordinary Logistic Regression shows separation/extreme probabilities, and there is no external validation.

SCIENTIFIC CONCLUSION

Promising workflow, limited evidence base.

The project demonstrates a reproducible path from real GOES time series to statistical detection, NOAA-linked event labels and leakage-controlled peak-time severity nowcasting. It does not establish operational forecasting or broad generalization.
