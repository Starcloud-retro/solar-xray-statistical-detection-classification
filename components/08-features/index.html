08 · FEATURES & LEAKAGE

Machine learning does not see the whole flare curve. It receives five carefully chosen rise-phase measurements.

The prediction time is fixed at the observed peak. Anything that would require post-peak information is forbidden from the primary predictor set.

FEATURE 1

Background flux

bg_flux describes the local pre-event level before the rise begins.

FEATURE 2

Rise duration

The horizontal distance from START to PEAK tells us how long the impulsive rise lasted.

FEATURES 3–5

How strongly and how quickly did the signal rise?

rise_slope, max_roc and mean_pos_roc summarize the shape of the rise using only START→PEAK information.

LEAKAGE GATE

Everything after the peak is locked out

Decay duration, decay slope and other post-peak morphology are unavailable at the prediction time, so they cannot be primary predictors.

WHY NOT PEAK FLUX?

Peak flux would give away too much of the label definition

NOAA flare class is defined from peak soft X-ray flux. Therefore peak_flux is descriptive only and is excluded from the five primary predictors.
