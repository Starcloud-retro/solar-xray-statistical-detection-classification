An unusual event needs more than “the line looks high.” We measure distance, speed and persistence.

The detector uses three point-wise cues: standard Z, robust Z and log-flux rate of change. Threshold crossings must persist for at least three consecutive minutes before they contribute to detection.

CUE 1

How far above the mean?

Standard Z divides the current point’s distance from the rolling mean by the rolling sample SD.

CUE 2

What if the background itself contains extreme values?

Robust Z replaces mean/SD with median/scaled-MAD. It asks the same distance question using a more resistant reference.

CUE 3

How fast is the signal changing?

ROC is the one-minute difference in log10 flux. A fast rise can reveal impulsive behavior even when absolute level alone is ambiguous.

PERSISTENCE

One extreme minute is not enough

Each cue is persistence-filtered. A threshold crossing must belong to a run of at least three consecutive true points.

SEGMENTATION

Persistent minutes become an event interval

Once the boolean detections form a run, the project extracts START, PEAK and END. Across the study window this process produced 115 detected event intervals.
